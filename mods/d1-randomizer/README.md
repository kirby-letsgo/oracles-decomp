# Randomizer (D1 preview)

Bundled with the app and disabled by default. Enable in Settings → Mods → Official mods.
Seasons only, fixed seed `first` from the `seasons-d1-optional` preset. Map and Gasha rewards
exchange places; compass is unchanged. The script is the generator output for that seed.
Only these three optional D1 chests participate; progression remains vanilla.

Use a fresh unlinked save and keep the toggle enabled for that run. Changes apply on the next
game start. There is no seed picker or save binding yet. Native replay verifies both changed
pickups; full-dungeon completion and EU playtesting remain outstanding.
